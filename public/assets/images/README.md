# Image Assets

Use this folder for all local site images.

## Structure
- `logo/` — brand logo files (SVG/PNG, light/dark variants)
- `hero/` — homepage hero visuals
- `products/` — product and section imagery
- `icons/` — UI icons and badges
- `og/` — social share images (Open Graph/Twitter)

## Suggested filenames
- `logo/permacool-logo-light.svg`
- `logo/permacool-logo-dark.svg`
- `logo/permacool-mark.svg`
- `hero/home-hero-main.webp`
- `og/permacool-og-home.jpg`

Prefer modern formats (`webp`, `svg`) when possible.
